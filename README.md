# Personal Portfolio

A modern personal portfolio website built using **HTML5 and CSS3**. The website showcases my background, technical skills, programming projects, education, professional experience, and learning journey as an Information Technology student.

## Features

* About Me section
* Technical Skills section
* Technologies and tools used
* Project showcase
* Education background
* Professional experience
* Current learning journey
* GitHub, LinkedIn, and Facebook profiles
* Hobbies and personal interests
* Contact form
* Responsive design for desktop, tablet, and mobile
* Smooth scrolling navigation
* Interactive hover effects
* Custom dark-themed styling
* Green accent color throughout the website
* Profile picture section
* Project technology tags

## How to Run

1. Download or clone the repository.
2. Make sure the project files are in the same folder.
3. Make sure the `images` folder contains the profile picture.
4. Open `index.html` in your web browser.

For easier development, the website can also be opened using **Visual Studio Code with Live Server**.
